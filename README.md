Proyecto segundo parcial

Aplicación: Registro de alumnos y Calificaciones

Product Backlog

Épica 1 - Registro de Alumnos
-US1: Como usuario, quiero registrar un alumno con nombre, grupo y cinco calificaciones, para llevar un control academico.
-US2: Como usuario, quiero que el sistema valide que todos los campos estén llenos y las calificaciones sean números validos, para evitar errores de captura.

Epica 2 - Consulta de Alumnos
-US3: Como usuario, quiero ver la lista de alumnos en un DataGridView, para conocer los datos registrados.
-US4: Como usuario quiero que la tabla muestre automáticamente el promedio de cada alumno, para ver rápidamente su rendimiento.
-US5: Como usuario, quiero buscar alumnos por nombre o grupo, para localizarlos facilmente.

Épica 3 - Modificación de datos
-US6: Como usuario, quiero editar los datos de un alumno registrado, para corregir o actualizar informacion.

Épica 4 - Eliminación de alumnos
-US7: Como usuario, quiero eliminar un alumno con confirmacion previa, para mantener limpia la lista y evitar borrar por accidente.

Épica 5 - Reportes y alertas(mejora opcional)
-US8: Como usuario quiero que se muestre un mensaje personalizado según el promedio (Reprobado, Bien pero puedes mejorar, Muy bien), para dar retroalimentación
inmediata.
-US9: Como usuario quiero ver un conteo de cuantos alumnos aprobaron y reprobaron, para analizar el rendimiento del grupo.
-US10: Como usuario, quiero exportar la lista de alumnos a un archivo de texto exel, para compartirlo con otros docentes.
